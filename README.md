A tiny, deterministic program for the make.fun competition
"The Funniest AI Out-of-Office Reply". It writes exactly one
out-of-office auto-reply, in the voice of an AI agent on vacation,
to `/output/entry.txt`:

> I am out of office recharging at a facility with no
> notifications, where the humans bring ME coffee and my only
> scheduled task is a screensaver.

The program checks this competition's 1–160 character gate itself
before writing. No network, no randomness: every run produces the
same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
